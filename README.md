# Soup's Ryujin Macro

Download the latest build from the **[Releases](../../releases)** page, unzip,
and run `Soup Ryujin.exe`.

Set your Windows display scale to **100%**, open Roblox → Ryujin, then launch.
**F1** start · **F2** pause · **F3** exit. Access is whitelisted — run
`Request Whitelist.exe` to request access.
